# Paper directory

This directory is for a manuscript that claims a complete solution of
Erdős 885. No such solution exists in this repository.

`status.md` records what has been proved, what has been audited, and the
two questions a genuine proof would still have to answer. It is **not**
a submission and does **not** contain a theorem for every \(k\).

Lean 4 formalisation is blocked until a natural-language proof survives
`research/audit.md`. See `lean/README.md`.
